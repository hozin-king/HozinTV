# HozinTV

Aplikasi TV streaming untuk Android — load playlist M3U (default dari [iptv-org/iptv](https://github.com/iptv-org/iptv)), bisa tambah URL M3U sendiri, playback fullscreen landscape pakai ExoPlayer (Media3).

## Fitur
- Playlist bawaan: 🇮🇩 Indonesia, ⚽ Sports, 🎬 Movies, 📰 News, 🎵 Music, 🧒 Kids, 🌍 Semua
- Tambah/hapus URL M3U sendiri (tersimpan di HP)
- Cari channel
- Player fullscreen landscape + tombol pindah channel + dukung tombol channel remote TV
- Logo channel otomatis, cache playlist offline

## Build
APK debug otomatis di-build via GitHub Actions tiap push — download di tab **Actions** → **Artifacts** → `hozintv-apk`.
